Como usar Markdown

Markdown é uma forma simples de formatar o texto da descrição das suas tarefas.

O básico

Você escreveO resultado fica assim
# TítuloTítulo grande
## SubtítuloSubtítulo
**importante**importante
*ênfase*ênfase
`código`código
- primeiro item
- segundo item		• primeiro item
• segundo item

Exemplo de uma tarefa

Texto digitado:

# Revisar Física

## Antes da prova

- Rever movimento uniforme
- Fazer exercícios 4 a 8
- **Separar dúvidas**

Lembrete: levar o caderno.

Como a descrição será exibida:

Revisar Física

Antes da prova

  • Rever movimento uniforme
  • Fazer exercícios 4 a 8
  • Separar dúvidas

Lembrete: levar o caderno.

Dicas rápidas

  • Use # para criar títulos e ## para subtítulos.
  • Use listas com - no começo da linha.
  • Use **texto** para destacar algo importante.
  • Você não precisa usar Markdown em toda tarefa. Texto normal também funciona.
  • Na página de tarefas, o botão Como usar Markdown? leva você de volta para este guia.
