# Nexo

**Nexo** is a web platform for organizing school routines and studying. It brings assignments, projects, exams, and personal tools together in one place, with an interface designed for both desktop and mobile devices.

**Languages:** [Português](README.md) · [English](README.en.md)

## Features

- **School agenda:** organize assignments and projects with due dates.
- **Exam roadmap:** check exam dates and the topics to study.
- **Student area:** personal tasks, grades, calendar, study tools, and statistics.
- **My tables:** create custom tables to organize information.
- **Custom themes:** personalize the platform's appearance.
- **Exit queue:** an organization tool for teachers and administrators.
- **Admin panel:** manage users, content, and requests.
