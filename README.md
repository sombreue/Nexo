# Central do Site
Uma plataforma web voltada à organização da rotina escolar, reunindo tarefas, trabalhos, provas e ferramentas para facilitar os estudos.
JavaScript
Node.js
Express
PostgreSQL

Funcionalidades
- Organização de tarefas e trabalhos escolares.
- Consulta de provas e planejamento de estudos.
- Personalização visual por meio de temas.
- Interface adaptada para computadores e dispositivos móveis.
- Painel administrativo para gerenciamento do conteúdo.
  
Acessar o projeto: https://github.com/sombreue/agenda-de-casa
Acessar o site publicado: https://agenda-de-casa.onrender.com/
